## Project Description & Tech Stack
**mess_app_staff** is a Flutter application designed for mess staff to efficiently verify and manage meal tokens for users via QR code scanning. The app streamlines the process of checking meal eligibility, marking usage, and updating user photos.

This is an Android client for the Mess Backend.

Link to [Mess-Backend](https://github.com/as1605/Mess-Backend) code repository

**Tech Stack:**
- Flutter (Dart)
- REST API (Dio, Cookie management)
- QR Scanning (mobile_scanner)
- Camera & Image Processing (camerawesome, image)
- State management via Flutter widgets

## Installation & Building

Connect with the backend and fill the `serverUrl` in [constants.dart](lib/utils/constants.dart)

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd mess_app_staff
   ```
2. **Install dependencies:**
   ```bash
   flutter pub get
   ```
3. **Run on device/emulator:**
   ```bash
   flutter run
   ```
4. **Build APK for Android:**
   ```bash
   flutter build apk --release
   # The APK will be at build/app/outputs/flutter-apk/app-release.apk
   ```
5. **Share APK:**
   - Transfer the APK to your mobile device and install it.
   - You might need to give some permissions to install the app from external source

## Usage Guide for Mess Staff
### Login & Home
- On launch, the app checks if you are logged in. If not, enter your staff username and password.
- The home screen has:
  - **Scan**: Start QR code scanning for user meal tokens.
  - **Logout**: Log out of the app.

### Scanning Flow
- Tap **Scan** to open the QR scanner.
- Point the camera at a user's QR code. If valid, you are taken to the user's details screen.
- If the QR is invalid, an error popup appears.

### User Details Screen
- Shows user info, active meals, and all meals.
- **Edit**: Update the user's photo using the device camera.
- **Meal Cards**:
  - Green: Active/unused meal token.
  - Red: Used meal token.
  - Tap an active meal to mark it as used ("Scratch").

## Important API Endpoints
- `POST /auth/login` — Staff login
- `POST /auth/logout` — Logout
- `GET /auth/myProfile` — Get current staff profile
- `GET /staff/verifyToken?kerberos=...&token=...` — Verify user meal token
- `GET /staff/getMealTokens?kerberos=...` — List all meal tokens for a user
- `POST /staff/useMealToken` — Mark a meal token as used
- `POST /staff/uploadPhoto` — Upload or update user photo
- `GET /staff/photo/{photoId}` — Get user photo
